Retail Sentiment App
◦ Tech Stack: Python, Pandas, Flask, HTML, CSS, Pandas, SQL, Git 
◦ Every product online gets hundreds even thousands of customer reviews but for retailers, going through all those reviews manually is time-consuming and repetitive. 
◦ Built a sentiment analysis and summarization web app using NLP (NLTK, TextBlob) with over 92% sentiment detection accuracy. 
◦ Retailers can input product review links and instantly view 100% auto-generated insights, including sentiment breakdown and top pros/cons. 
◦ Achieved a 70% reduction in manual review time by automating the analysis of product feedback using NLP techniques. 
◦ Implemented retailer authentication (Login/Register) and integrated a MySQL-backed database for managing user sessions and data securely.
